Cours 7 — La cartographie web, partie 3

Exemples de code présentés en classe : API Google Maps, OpenLayers 10, Leaflet, MapLibre, applications PWA et page générée avec l'IA générative.

Pour travailler sur votre poste, téléchargez le dépôt (bouton Code › Download ZIP sur GitHub) et ouvrez les pages avec un serveur local : python -m http.server puis http://localhost:8000. En file://, les GeoJSON et les service workers ne se chargent pas.
